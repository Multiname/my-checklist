# Этап 1: Пустой проект
## Цель
Подготовить основание приложения и убедиться, что оно запускается на моем смартфоне

## Результат
- Налаженный скилл и инструмент для запуска текущей версии приложения на смартфоне, подключенном по USB
- Приложение запускается на смартфоне

## Зависимости
Нет

# Этап 2: Категории
## Цели
Реализовать функционал категорий без пунктов

## Результат
- Рабочие кнопки button_area/create_category, button_area/rename_category, button_area/delete_category
- Категории можно создавать и задавать им название
- Категории можно выделять
- Категории можно перемещать, обновляя их порядок в списке
- Категории можно переименовывать
- Категории можно удалять
- Данные категорий сохраняются и восстанавливаются при повторном запуске приложения
- Работает скролл

## Зависимости
Выполненный этап 1

# Этап 3: Пункты
## Цели
Реализовать функционал пунктов

## Результат
- Рабочие кнопки button_area/add_item, button_area/rename_item, button_area/delete_item
- Пункты можно добавлять и задавать им название
- Пункты можно выделять
- Пункты можно перемещать - как в рамках прежней категории, так и за ее пределами, - обновляя их порядок в списке
- Категории можно переименовывать
- Пункты можно удалять
- Пункты удаляются вместе с удалением категории
- Можно отмечать пункты и снимать с них отметку
- Данные пунктов сохраняются и восстанавливаются при повторном запуске приложения

## Зависимости
Выполненный этап 2
