# Project Intent: Мобильный чеклист
## Цель
Создать мобильное приложение для ведения списка чекбоксов

## Решаемая проблема
В данный момент я пользуюсь обычными заметками на телефоне. Для обычного чеклиста функционал заметок слишком избыточен и неудобен как в использовании, так и в представлении

## Критерии приемки
- Можно создавать, переименовывать, перемещать и удалять категории
- Можно добавлять, переименовывать, перемещать и удалять пункты внутри категорий
- Можно отмечать пункты и снимать с них отметку
