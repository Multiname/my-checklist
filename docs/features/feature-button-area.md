# feature-button-area — область кнопок

## Краткое описание
button_area - это контейнер в правом нижнем углу, в котором находятся круглые кнопки с иконками

### Список кнопок
- create_category - добавить категорию
- rename_category - переименовать категорию
- delete_category - удалить категорию
- add_item - добавить пункт
- rename_item - переименовать пункт
- delete_item - удалить пункт

## Подробности
### create_category
- Имеет иконку "плюс"
- Видна всегда, пока не выделена категория
- Когда категория выделена, заменяется на add_item
- Когда выделен пункт, категория не выделена, поэтому снова видна create_category

### rename_category
- Имеет иконку "карандаш"
- Видна, пока выделена категория
- Когда выделен пункт, заменяется на rename_item

### delete_category
- Имеет иконку "корзина"
- Видна, пока выделена категория
- Когда выделен пункт, заменяется на delete_item

### add_item
- Имеет иконку "плюс"
- Видна, пока выделена категория

### rename_item
- Имеет иконку "карандаш"
- Видна, пока выделен пункт

### delete_item
- Имеет иконку "корзина"
- Видна, пока выделен пункт

### Дополнительно
- Кнопки физически не пересоздаются: плюс, карандаш и корзина — одни и те же
  три слота, у которых при смене выделения меняется действие (обработчик,
  подпись для TalkBack и видимость). Для пользователя это неотличимо: иконки и
  положение прежние, кнопка «заменяется» на месте, список не сдвигается
- Пока идёт ввод (открыта клавиатура), кнопки не показываются: контейнер целиком скрыт и возвращается в правый нижний угол после завершения ввода. Правило действует для всех кнопок
- При открытии клавиатуры контейнер не смещается вверх: на время ввода он скрыт
- Пока категория перетаскивается (drag and drop), кнопки также не показываются: контейнер целиком скрыт. Правило действует для всех кнопок. После отпускания панели кнопки возвращаются на место — те, что соответствуют текущему выделению (перетаскивание выделение не снимает)
- Пока перетаскивается пункт, контейнер скрыт по той же причине: поднятая строка
  и зазор не должны оказываться под кнопками
