# Краткое описание
button_area - это контейнер в правом нижнем углу, в котором находятся круглые кнопки с иконками

## Список кнопок
- create_category - добавить категорию
- rename_category - переименовать категорию
- delete_category - удалить категорию
- add_item - добавить пункт
- rename_item - переименовать пункт
- delete_item - удалить пункт

# Подробности
## create_category
- Имеет иконку "плюс"
- Видна всегда, пока не выделена категория
- Когда категория выделена, заменяется на add_item

## rename_category
- Имеет иконку "карандаш"
- Видна, пока выделена категория
- Когда выделен пункт, заменяется на rename_item

## delete_category
- Имеет иконку "корзина"
- Видна, пока выделена категория
- Когда выделен пункт, заменяется на delete_item

## add_item
- Имеет иконку "плюс"
- Видна, пока выделена категория

## rename_item
- Имеет иконку "карандаш"
- Видна, пока выделен пункт

## delete_item
- Имеет иконку "корзина"
- Видна, пока выделен пункт

## Дополнительно
- При открытии клавиатуры контейнер не смещается вверх, а перекрывается клавиатурой
