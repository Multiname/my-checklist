# feature-item — пункты

## Краткое описание
### Цель
Пункты - это небольшое напоминание о чем-то, что может считаться в данный момент выполненным (отмеченным) или ожидающим выполнения (не отмеченным)

### Список функций
- Пункты можно создавать
- Пункты можно выделять
- Пункты можно переименовывать
- Пункты можно перемещать
- Пункты можно удалять
- У пунктов есть отметка

## Подробности
### Пункты можно создавать
- При выделении категории button_area\create_category заменяется на button_area\add_item
- При нажатии на button_area\add_item в конец списка добавляется новый пункт
- Во время добавления нового пункта пользователю сразу же предлагается ввести его название
- Если пользователь оставил название пустым, то пункт называется как "Пункт"

### Пункты можно выделять
- Пункт считается выделенным, если:
    - он находится внутри выделенной категории и по нему был совершен тап (выделение с категории снимается)
    - никакая категория в данный момент не выделена, а по пункту было совершено долгое нажатие
- Выделенный пункт имеет отличительный цвет заднего фона
- Когда пункт выделен, в button_area показываются соответствующие кнопки (см. [feature-button-area.md](feature-button-area.md))
- Когда выделение отменяется, то соответствующие кнопки button_area скрываются
- Выделение можно отменить тапом (не путать с drag and drop) по любой области кроме кнопок button_area, а также кнопкой "назад"

### Пункты можно переименовывать
- По нажатию на button_area\rename_item пользователю предлагается изменить название выделенного пункта
- Ввод текста происходит на месте, где находится текст пункта, заменяя его
- Ввод заканчивается после нажатия на любую область кроме клавиатуры или нажатия на кнопку "назад", сохраняя текущее введенное значение, но не отменяя выделение пункта
- Если название пункта не вмещается в строку, то оно начинает занимать две строки

### Пункты можно перемещать
- Выделенный пункт можно перетаскивать (drag and drop)
- Перетаскивание начинается только после выделения и вторым жестом: первое долгое нажатие выделяет пункт, палец отпускается, и второе долгое нажатие по нему же его поднимает
- Во время перетаскивания пункта категории не "сворачиваются"
- Пункт можно перетаскивать как в пределах категории, так и в другие категории
- Если перетащить пункт в другую категорию, то эта категория начнет хранить данный пункт вместо прежней
- В любом случае, если пункт поменял свое положение относительно других пунктов, то новый порядок пунктов сохранится

### Пункты можно удалять
- По нажатию на button_area\delete_item происходит удаление выделенного пункта

### У пунктов есть отметка
- Слева от пункта всегда есть чекбокс
- Чекбокс может быть отмечен или не отмечен
- По нажатию на чекбокс его состояние меняется на противоположное (если не выделена категория или какой-либо пункт)
- Отмеченные пункты имеют серый цвет
