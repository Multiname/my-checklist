# feature-scroll — прокрутка

## Краткое описание
### Цель
Длинный список категорий с пунктами должен прокручиваться, а при перетаскивании —
прокручиваться сам, чтобы элемент можно было унести в невидимую часть списка.

### Список функций
- Список категорий и пунктов прокручивается вертикально
- Во время перетаскивания категории или пункта список прокручивается автоматически,
  когда перетаскиваемый объект близко к верхней или нижней границе экрана
- Прокрутка не меняет выделение и не сбрасывает ввод названия

## Подробности
### Обычная прокрутка
- Прокручивается всё содержимое экрана: категории вместе с их пунктами
- Прокрутка списка не снимает выделение категории или пункта: жест уходит списку, а не
  `GestureDetector` элемента
- Положение прокрутки не сохраняется: при запуске список открывается сверху
- Кнопки `button_area` не перекрывают содержимое: нижний отступ списка постоянный,
  поэтому при скрытии и показе кнопок список не сдвигается
- После создания категории список прокручивается к концу — видно новую категорию и
  поле ввода названия

### Автопрокрутка при перетаскивании
- Автопрокрутка включается, когда перетаскиваемый объект подходит близко к верхней
  границе видимой области, — список едет вверх; так же к нижней — вниз
- Для пункта зона считается по самой поднятой строке, для категории — по полосе её
  названия: длинная категория, чей низ уходит за экран, но название в середине, список
  не двигает
- Прокрутка идёт плавно и с постоянной скоростью, пока палец остаётся у границы, и
  останавливается, когда палец уходит из зоны или объект отпущен
- Прокрутка не уезжает за край списка и не пружинит обратно
- Перетаскиваемый объект остаётся ровно под пальцем, без отставания и рывков: экран
  в движении обновляет только его и место вставки, а не всю страницу
- Пока идёт автопрокрутка, перетаскиваемый объект остаётся под пальцем, а место
  вставки пересчитывается: элемент можно донести до невидимой категории, не отпуская
  палец
- Прокрутка списка пальцем во время перетаскивания означает, что жест потерян:
  перетаскивание снимается без записи в БД

## Сценарии приёмки
1. Дано: категорий больше, чем помещается на экран. Когда пользователь ведёт палец по
   списку. Тогда список прокручивается, выделение не меняется.
2. Дано: выделенный пункт перетаскивается к нижней границе экрана. Когда палец
   задерживается у границы. Тогда список прокручивается вниз, пункт остаётся под
   пальцем, и его можно отпустить в категории, которая была за экраном.
3. Дано: перетаскивается длинная категория, её название в середине экрана. Когда
   пользователь ведёт её вверх. Тогда список не прокручивается, пока название не
   подойдёт к границе.
4. Дано: палец у границы списка, список уже прокручен до конца. Когда пользователь
   держит палец. Тогда список стоит на месте — без прокрутки за край и без отскока.
5. Дано: пользователь начал перетаскивание и прокрутил список пальцем. Когда жест
   отпущен. Тогда перетаскивание снято, порядок в БД не изменился.
