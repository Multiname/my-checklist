# Цель
Реализовать функционал добавления категорий

# Шаги
- Добавить прокручиваемый контейнер на весь экран
- Создать шаблон категории: название поверх прямоугольной панели
- Добавить кнопке create_category функционал нажатия: в контейнер в конец списка добавляется новая категория с названием "Категория"
- Реализовать: после создания категории появляется клавиатура и пользователю предлагается ввести название категории
- Введенное название сохраняется в БД и восстанавливается при повторном запуске приложения

# Результат
Можно создавать новые категории, сохраняющиеся в БД
