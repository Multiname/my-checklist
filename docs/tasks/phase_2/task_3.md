# Цель
Реализовать выделение категорий

# Шаги
- Реализовать: долгое нажатие по панели, на которой расположена категория, выделяет ее
- Реализовать: выделение дает виброотклик и меняет цвет категории
- Реализовать: тап по любой области кроме кнопок button_area сбрасывает выделение
- Реализовать: нажатие кнопки \ активация жеста "назад" сбрасывает выделение
- Реализовать: при выделении create_category скрывается, а rename_category и delete_category показываются - и наоброт

# Результат
Категории можно выделять. Такие категории визуально отличаются от остальных категорий. Пользователю показываются только актуальные кнопки из button_area
