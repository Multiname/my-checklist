# Цель
Реализовать перетаскивание категорий

# Шаги
- Реализовать: на выделенную категорию работает drag and drop
- Реализовать: drag начинается сразу же после выделения, палец отпускать и нажимать еще раз теперь не нужно
- Реализовать: через drag and drop категорию можно переставлять выше или ниже других категорий
- Реализовать: новая позиция категории в списке сохраняется в БД и восстанавливается при повторном запуске приложения

# Результат
Категории можно переставлять в списке через drag and drop, новый порядок сохраняется
