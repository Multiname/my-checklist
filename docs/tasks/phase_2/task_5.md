# Цель
Реализовать переименовывание категорий

# Шаги
- При выделенной категории по нажатию на rename_category текст категории заменяется на поле ввода (сохраняя прежнее значение), появляется клавиатура и пользователю предлагается ввести новое название
- Кнопка / жест "назад" или тап по области вне клавиатуры закрывает клавиатуру и задает новое название выделенной категории
- Новое название сохраняется в БД и восстанавливается при запуске приложения

# Результат
Выделенные категории можно переименовывать через rename_category
