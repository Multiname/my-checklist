# Цель
Создать кнопки управления пунктами

# Шаги
- В контейнер button_area добавить кнопки add_item, rename_item, delete_item
- Кнопка add_item показывается при выделении категории (визуально заменяет кнопку create_category) и скрывается в остальных случаях
- Кнопки rename_item, delete_item пока что остаются скрытыми

# Результат
Кнопки из button_area в нужный момент соответствуют пунктам или категориям
