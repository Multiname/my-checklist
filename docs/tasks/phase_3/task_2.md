# Цель
Реализовать функционал добавления пунктов

# Шаги
- Создать шаблон пункта: чекбокс слева и название
- Добавить в шаблон категории контейнер для пунктов
- По нажатию на add_item в выделенной категории в конец списка добавляется новый пункт с названием "Пункт"
- После создания пункта появляется клавиатура и пользователю предлагается ввести название пункта
- Введенное название сохраняется в БД и восстанавливается при повторном запуске приложения

# Результат
Можно создавать новые пункты, сохраняющиеся в БД
