# Цель
Реализовать выделение пунктов

# Шаги
- Долгое нажатие по пункту выделяет его
- Выделение дает виброотклик и меняет цвет фона пункта
- Тап по любой области кроме кнопок button_area сбрасывает выделение
- Нажатие кнопки / активация жеста "назад" сбрасывает выделение
- Нажатие по пункту внутри выделенной категории также приводит к выделению пункта (выделение с категории сбрасывается)
- При выделении rename_item и delete_item показываются - и наоброт

# Результат
Пункты можно выделять. Такие пункты визуально отличаются от остальных пунктов. Пользователю показываются только актуальные кнопки из button_area
