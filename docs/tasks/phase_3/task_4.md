# Цель
Реализовать перетаскивание пунктов

# Шаги
- На выделенный пункт работает drag and drop
- Drag начинается сразу же после выделения, палец отпускать и нажимать еще раз теперь не нужно
- Через drag and drop пункт можно переставлять выше или ниже других пунктов в рамках его категории
- Новая позиция пункта в списке сохраняется в БД и восстанавливается при повторном запуске приложения
- Теперь пункт можно перетаскивать в другие категории
- Положение пункта среди пунктов другой категории и его соответствие новой категории сохраняется в БД и восстанавливается после перезапуска приложения

# Результат
Пункты можно переставлять в списке через drag and drop - как в пределах прежней категории, так и за ее пределами, новый порядок сохраняется
