# Цель
Реализовать переименовывание пунктов

# Шаги
- При выделенном пункте по нажатию на rename_item текст пункта заменяется на поле ввода (сохраняя прежнее значение), появляется клавиатура и пользователю предлагается ввести новое название
- Кнопка \ жест "назад" или тап по области вне клавиатуры закрывает клавиатуру и задает новое название выделенного пункта
- Новое название сохраняется в БД и восстанавливается при запуске приложения

# Результат
Выделенные пункты можно переименовывать через rename_item
