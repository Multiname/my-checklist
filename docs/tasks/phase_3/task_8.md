# Цель
Реализовать отметку пунктов

# Шаги
- При нажатии на чекбокс пункта он переключает свое состояние: отмеченный \ не отмеченный
- Отмеченные пункты имеют более серый цвет
- Состояние отметки сохраняется в БД и восстанавливается при перезапуске приложения

# Результат
Можно отмечать пункты и снимать с них отметку
